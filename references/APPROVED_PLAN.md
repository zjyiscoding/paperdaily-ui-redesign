# PaperDaily 全站 UI：模块归类与统一元素改造建议

> 文档用途：把原 M0–M19 元素清单转为可复用的 UI 组件清单，供静态原型设计与开发者评审。  
> 交付内容：① 板块与元素归类；② 小元素的具体修改建议及参考网站。  
> 基础材料：《PaperDaily_全站UI最小改动模块与元素清单.md》。

## 阅读说明

这次合并的是**设计与样式的重复工作，不是网站的业务板块**。例如，“保存论文”“保存综述矩阵”“保存账户设置”可以共用按钮外观，但仍执行各自原来的操作。

**目标结构：12 类通用组件 → 8 类可复用组合板块 → 原有页面。** 原来的页面、URL、数据字段、权限与业务流程不因这次归类而合并。

原清单中尚未核实的登录后元素仍属于待核对项。本文不是对线上网站的重新实测；“适用范围”表示原清单中的覆盖位置，不表示已确认该功能在线上存在。没有实际存在的控件，不必为了凑齐清单而新增。

文中的尺寸是本项目的**建议初值**，不是原站测量结果，也不是参考网站要求照抄的数值。参考网站用于查看组件示例与交互方式，不代表需要引入其组件库。

### 改动等级

| 标记 | 含义 | 使用边界 |
|---|---|---|
| S：样式优先 | 字体、颜色、边框、圆角、间距、已有状态的外观 | 通常以 CSS 为主；是否需要补充 class 或包装节点，仍取决于现有代码 |
| U：局部 UI 交互 | 展开收起、浮层开合、可访问名称、键盘操作、按钮反馈等 | 可能需要调整 HTML 与少量前端代码；不等于修改后端 |
| S / U | 已有对应交互时主要换样式；没有时才涉及 U | 不把“新增交互”包装成“只换 CSS” |

**默认边界：不新增后端接口，不改检索/生成算法，不改登录鉴权，不改计费、权限与任务状态机。是否增加原站没有的前端交互，单独交由开发者确认。**

# 一、板块与元素的合并归类

## 1.1 十二类通用组件

同类元素集中设计一次，各页面引用同一套样式与状态规则。下表中的“同类”不意味着所有成员都使用完全相同的 HTML 结构。

| 编号 | 归类 | 合并后的元素范围 | 原清单来源 | 共用与保留的边界 |
|---|---|---|---|---|
| A01 | 页面框架与导航 | 页面根容器、内容区、侧边栏、顶部栏、页脚、导航项、页签、面包屑、目录锚点、分页 | M0、M1、M2、M9、M14、M19；其他页面的外壳 | 框架共用间距与层级；导航、页签、分页是同族中的不同子组件，不共用一份点击逻辑 |
| A02 | 文字、图标与身份形象 | 页面标题、区块标题、正文、摘要、辅助文字、列表文字、图标、Logo、头像、占位形象 | 所有 M 模块；M1、M14、M17 尤其集中 | 统一字号、字重、行高与图标规格；品牌素材和内容原样保留 |
| A03 | 按钮与链接 | 登录、注册、保存、新建、生成、导出、下载、编辑、删除、确认、取消、返回、关闭、复制、更多操作、原文与 DOI 链接 | M1–M18 中的操作入口；M3 是基础定义 | 一套按钮基础样式加少量变体；文案、点击处理函数、权限分别保留 |
| A04 | 文本输入与表单 | 搜索、研究问题、标题、DOI、邮箱、密码、邀请码、API Key、批注、问题描述、标签文字、校验提示、字数统计 | M3–M6、M8、M11–M14、M16、M17 | 输入框共用外壳；单行、多行、密码、只读值保留各自语义 |
| A05 | 选择、筛选与数值范围 | 下拉框、多选框、单选框、全选、反选、开关、日期、年份、范围、滑杆、排序条件、筛选条件 | M3、M6–M8、M11–M13、M15、M17 | 共用尺寸、选中与禁用视觉；不把复选框、开关、单选框互相替换 |
| A06 | 标签、徽标与元信息 | 主题标签、数量徽标、未读数、摘要级/全文级、任务状态、审核状态、私有/公开、时间、版本、作者、期刊、来源 | M1–M3、M5–M18 | 共用标签与元信息样式；主题、状态、证据级别、权限分别表达，不混成一个字段 |
| A07 | 卡片、列表与信息面板 | 论文卡片、综述卡片、问题卡片、方法卡片、数据集卡片、指标卡片、资源列表、详情信息、关联论文/证据列表 | M5–M8、M10–M13、M15–M18 | 复用容器、标题、内容、操作区；内容插槽按业务保留，不能强行统一字段 |
| A08 | 表格与比较矩阵 | 综述矩阵、检索表格、统计明细、API Key 列表、账单/使用记录、表头、单元格、选择列、排序、固定区域、工具栏 | M3、M6、M8、M11、M14–M17 | 共用表格外观与行内控件；列配置、排序、分页和数据来源不合并 |
| A09 | 浮层、菜单与提示气泡 | 下拉操作菜单、账户菜单、右键菜单、Tooltip、Popover、模态框、确认框、详情抽屉、预览浮层 | M0、M1、M3、M6、M11–M14、M16、M17、M19 | 复用容器与层级；提示、操作菜单、确认对话框保留不同交互职责 |

| A11 | 滚动、展开与区域尺寸 | 页面/列表/表格滚动条、横向滚动、摘要展开、说明折叠、行展开、导航收起、面板拖动、拖放反馈 | M0、M1、M3、M5–M19 中已有的相关交互 | 共用交互提示与样式；滚动条、数值滑杆、面板分隔线不视为同一种控件 |
| A12 | 图表、图片与代码内容 | 统计图、图例、坐标轴、数据提示、引用网络视图（如存在）、图片、预览、代码块、命令、API 请求响应、文档预览 | M6、M14–M16；其他页面引用相同内容时 | 统一外围文字、容器与操作区；现有图表引擎、文档查看器和代码内容不替换 |

## 1.3 用通用组件组合成八类板块

这些是“相似区域的共用模板”，不是要求把原页面搬家或合并成新页面。

| 组合板块 | 包含的通用组件 | 可以复用到的原区域 | 不统一的部分 |
|---|---|---|---|
| B01 页面/区块标题与操作区 | A02 标题 + A06 元信息 + A03 操作 | 各页标题、矩阵标题、日报标题、详情标题 | 标题内容、当前操作、状态字段 |
| B02 搜索与筛选工具栏 | A04 输入 + A05 筛选 + A06 已选条件 + A03 操作 | 论文、方法、数据集、深读、问题、统计筛选 | 筛选字段、联动关系、查询提交方式 |
| B03 资源列表与卡片 | A07 容器 + A02 文本 + A06 元信息 + A03 操作 | 论文、综述、问题、方法、数据集、最近记录 | 资源字段、内容密度与操作权限 |
| B04 详情与证据面板 | A07 信息区 + A02 正文 + A06 状态 + A11 展开 | 论文详情、深读结论、问题详情、数据集详情 | 证据内容、来源与数据类型；原位置或抽屉形式保留 |
| B05 表格与矩阵容器 | A08 表格 + B02 工具栏 + A01 分页 + A10 状态 | 矩阵、统计明细、Key、账单/使用记录 | 列配置、单元格类型、分页与排序逻辑 |
| B06 任务与状态面板 | A10 反馈/进度 + A06 状态 + A03 操作 | 问答、生成、深读、回传、问题追踪 | 实际任务状态、是否可取消/重试及权限 |
| B07 设置与身份表单 | A04 表单 + A05 选择 + A03 提交 + A10 反馈 | 登录、注册、偏好、账户、隐私、Key 配置 | 校验、保存时机、鉴权和敏感数据处理 |
| B08 长文与说明内容区 | A02 排版 + A01 目录 + A12 媒体/代码 + A11 折叠 | 回答、日报正文、帮助、Agent 文档、更新日志 | 原章节、图片、代码、引用与内容顺序 |

指标卡片与图表面板仍属于 A07、A12；它们可以放入任何原有页面，不需要另建一个“统计页面模板”。

## 1.4 可以共用，但不能混为一谈的元素

| 容易混淆的元素 | 可共用 | 必须保留的区别 |
|---|---|---|
| 保存、导出、登录、生成按钮 | 按钮基样式、尺寸、图标位置 | 原点击行为、主次级别、加载与权限判断 |
| 按钮与链接 | 字体、色彩、焦点视觉 | 按钮执行操作；链接保留地址和正常导航能力 |
| 标签、状态徽标、筛选项 | 圆角、字号、内边距 | 只读状态不能伪装成可点击筛选项 |
| 复选框、单选框、开关 | 尺寸、选中色、禁用外观 | 多选、互斥单选、开启关闭的语义不同 |
| Slider、Scrollbar、Splitter | 拖动反馈、焦点样式 | 分别改变数值、阅读位置、面板尺寸 |
| 空数据、无结果、未登录、无权限、加载失败 | 反馈面板容器 | 原因、文案与后续操作不能统一成“暂无数据” |
| 摘要级/全文级、任务状态、公开/私有 | 徽标外观 | 分属材料范围、任务进度、访问权限，不可混用 |
| Tooltip、菜单、确认弹窗 | 浮层底色、圆角、阴影 | 解释、选择操作、确认后果的职责不同 |

# 二、统一元素的具体修改建议

以下建议按 A01–A12 排列。每条均包含指定句式、可点击参考网站、参考重点和改动等级。一个元素在多个页面出现时，适用同一条建议，不重复设计。

## 2.0 共用的视觉参数

这些参数只定义一遍，后面的组件引用它们；初期沿用原站品牌强调色，不先做品牌重塑。

| 参数 | 本项目建议初值 |
|---|---|
| 色彩角色 | 页面浅中性色底、内容白底、深色正文、可读的次级文字、单一品牌强调色；成功/警告/错误另有语义色 |
| 字体 | 优先沿用原站可用字体，统一中文与英文的回退规则；暂不增加外部字体依赖 |
| 字号层级 | 页标题 28–32px；区块标题 20–22px；正文 16px；控件文字 14–16px；辅助信息 13–14px |
| 圆角 | 常规控件 8px；卡片/浮层 12px；标签视用途使用较小圆角或胶囊形 |
| 间距 | 4、8、12、16、24、32px；同层控件使用相同间距，不逐页面任意设置 |
| 常规控件高度 | 默认 40px；密集桌面区 32px；触屏场景优先提供 44px 左右的实际点击区域 |
| 边框与阴影 | 1px 轻边框；普通卡片尽量无重阴影；菜单、弹窗等悬浮层使用轻阴影 |
| 状态 | 默认、悬停、按下、键盘焦点、禁用、加载、选中、错误分别定义 |

参数组织方式参考 [Radix Theme](https://www.radix-ui.com/themes/docs/theme/overview) 与 [Spacing](https://www.radix-ui.com/themes/docs/theme/spacing)；上表是本项目建议，并非完整复刻其参数。

## 2.1 A01｜页面框架与导航

### A01.01 页面容器与区块边界

【对于全站页面容器与主内容区，我认为可以改成保留现有导航和板块顺序，只统一桌面内边距为 24px、窄屏内边距为 16px，并统一区块间距；矩阵使用可容纳宽表的区域，长文使用独立阅读宽度，不把所有页面锁死成同一种宽度，参考的图片/网站是[Ant Design · 布局](https://ant.design/components/layout-cn/)。】

**参考重点：**基本结构与响应式布局，不照搬其页面结构。  
**覆盖范围：**M0、M2、M4–M18、M19。**改动等级：**S；补充布局包装节点时涉及 U。

### A01.02 侧边导航与菜单项

【对于各页面的侧边导航项和文档导航项，我认为可以改成统一为图标、文字、可选数量徽标的对齐结构，默认行高约 40px；当前项使用轻背景与明确文字强调，其余项保留简洁底色，原分组、入口顺序与跳转不变，参考的图片/网站是[Ant Design · 导航菜单](https://ant.design/components/menu-cn/)。】

**参考重点：**内嵌菜单、选中态和缩起态。  
**覆盖范围：**M1、M14、M19。**改动等级：**S / U；只有原站已有的收起功能才默认保留。

### A01.03 页签

【对于工作台、方法与数据等区域的页签，我认为可以改成共用一套底部指示线式页签，文字 15–16px，活动项加粗并有明确指示；数量徽标放在标题后，窄区域横向滚动而非把文字压成多行，切换后的数据和路由逻辑保持不变，参考的图片/网站是[Radix Themes · Tabs](https://www.radix-ui.com/themes/docs/components/tabs)。】

**参考重点：**活动页签、内容区域与键盘切换。  
**覆盖范围：**M3、M8、M9、M19。**改动等级：**S / U。

### A01.04 面包屑与文档目录

【对于面包屑、返回定位与文档目录，我认为可以改成统一文字大小、链接与当前位置的区分；面包屑保留路径层级，目录保留章节层级和当前阅读项，不把两者改造成普通操作按钮，也不为没有层级的页面新增虚构路径，参考的图片/网站是[Ant Design · 面包屑](https://ant.design/components/breadcrumb-cn/)、[Ant Design · 锚点](https://ant.design/components/anchor-cn/)。】

**参考重点：**路径分隔与目录当前项标记。  
**覆盖范围：**M2、M14、M18。**改动等级：**S；新增阅读位置高亮属于 U。

### A01.05 分页

【对于论文、方法、数据集、记录列表中的分页器，我认为可以改成共用紧凑分页组件，数字按钮采用同一尺寸，当前页明确突出；“总数、每页条数、跳页”只在原接口与页面支持时保留，窄屏可使用简洁外观，不擅自把后端分页改为无限滚动，参考的图片/网站是[Ant Design · 分页](https://ant.design/components/pagination-cn/)。】

**参考重点：**基本、简洁、总数与跳转示例。  
**覆盖范围：**M3、M6、M8、M15、M17。**改动等级：**S / U。

## 2.2 A02｜文字、图标与身份形象

### A02.01 文字层级

【对于页面标题、区块标题、正文和辅助文字，我认为可以改成统一为少量字号层级：页标题 28–32px、区块标题 20–22px、正文 16px、辅助信息 13–14px；标题以字重而不是额外装饰强化，重要研究结论不使用过浅文字，参考的图片/网站是[Radix Themes · Typography](https://www.radix-ui.com/themes/docs/theme/typography)。】

# 三、低改动接入边界与共用检查项

## 3.1 同一套外观，不等于必须重写成同一组件库

第一轮可以只给现有元素增加受控的共用样式，例如统一按钮类名或统一主题变量；不要求开发者把网站重写成 React、Vue，也不要求同时安装 Radix、Ant Design、Carbon。

**视觉参考的分工：**基础控件以 Radix 的轻量表现作为主要参考；表单与选择控件参考 Ant Design 的具体示例；复杂数据表与图表参考 Carbon 的信息组织。最终仍然使用本项目统一的字号、圆角、间距与强调色，避免每个页面看起来像来自不同产品。

| 开发者愿意接受的范围 | 可以采用的内容 | 暂不纳入的内容 |
|---|---|---|
| 只接受换肤 | 文字层级、按钮尺寸、输入框外观、边框、圆角、卡片、标签、已有状态视觉 | 新交互、页面重排、数据字段改变 |
| 接受少量前端交互调整 | 在换肤基础上逐项确认展开收起、局部浮层、键盘反馈等 U 项 | 新接口、新权限、新业务流程 |
| 暂时只愿意改一个区域 | 在单个页面根节点内应用同一套组件样式，先展示该范围的效果 | 直接用全局选择器覆盖所有页面 |

这里的划分只是改动性质，不是工时承诺。现有 DOM、样式优先级、组件库与滚动结构仍需开发者核对。

## 3.2 所有组件共用的检查项

这些检查项横跨十二类组件，继承原 M19，不为每个页面重新规定一遍。

| 检查项 | 本项目统一约束 | 参考 |
|---|---|---|
| 键盘焦点 | 可操作控件聚焦后可辨认，不只提供鼠标 hover 外观 | [W3C：Focus Visible](https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html) |
| 点击区域 | 小图标与关闭按钮要有足够实际点击区域；本文的触屏 44px 是建议值，不将其写成所有场景的强制标准 | [W3C：Target Size (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) |
| 文字可读性 | 对每个文字与背景组合检查对比度；普通文字以至少 4.5:1 为目标，不能认为换成“灰色”就自然合格 | [W3C：Contrast (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) |
| 状态辨识 | 错误、选中、权限与证据级别同时通过文字、图标或结构表达，不只用颜色 | [W3C：Use of Color](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html) |
| 弹窗焦点 | 弹窗打开与关闭时焦点位置合理；模态与非模态行为不混用 | [W3C：Modal Dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) |
| 响应式 | 使用同一组件的宽窄变体；窄屏时不靠无限缩小字号塞入全部内容，也不据此改动功能或路由 | [Radix：Breakpoints](https://www.radix-ui.com/themes/docs/theme/breakpoints) |
| 完整状态 | 评审默认、hover、focus、disabled、loading、selected、error 等实际支持的状态 | [Radix：Playground](https://www.radix-ui.com/themes/playground) |

## 3.3 本次明确不包含

不新增拖拽排序、自动保存、全新筛选字段、全文获取能力、权限设置、付费升级流程或后端进度接口。原站不存在的这些能力，不会因为参考组件里有类似演示就自动列为必须实现。

不以原清单中未核实的功能为依据断言“现有网站一定有问题”。待核实项仍待核实；本文建议用于确定共享设计规则，而不是替代实际页面检查。
