# PaperDaily：三个典型页面的 UI 重设计原型

版本：UI Preview 01 · 2026-11-02

## 1. 打开方式

直接用现代浏览器打开以下任意 HTML。每一份都内嵌 CSS、JavaScript、示例数据和 SVG 图标，不需要安装依赖、不需要 CDN、不需要构建工具。

| 文件 | 对应的原页面 | 主要用途 |
|---|---|---|
| `01-review-matrix.html` | 文献综述工作台 `/workbench` | 观察密集数据表、长文本、批量操作、详情与状态之间的配合 |
| `02-dataset-map.html` | 数据集地图 `/hub/datasets` | 观察搜索、多条件筛选、标签、资源卡片、加载更多与详情信息 |
| `03-research-daily.html` | 公开示例日报 `/demo/daily` | 观察阅读排版、目录、论文卡片、说明展开、收藏与引用导出 |

三个 HTML 放在同一文件夹时，右上角“01 矩阵 / 02 数据 / 03 日报”可以相互切换。单独保存某一份也能独立运行，但不能跳转到没有一起保存的其他两份。

“原站”和带外链图标的入口会在新标签页打开 PaperDaily 或论文来源。静态文件不代理原站，也不共享原站登录态。

## 2. 为什么选这三页

这不是三个重复的首页，也不是独立于实际产品的组件陈列板。

**综述矩阵**代表“横向比较”。它集中展示表格、固定区、横向滚动、搜索、排序、选择框、半选状态、列显示、长内容展开、危险确认、保存表单、详情抽屉、引用代码和生成状态。

**数据集地图**代表“寻找与筛选资源”。它沿用原站的研究问题入口、名称搜索、学科大类、子领域、获取方式、类型、观测单位、地区和排序等字段，并保留“加载更多”和备用标签搜索的结构。

**研究日报**代表“持续阅读与内容整理”。它保留原站的公开示例定位和“今日地图—必读—视野更新—拓展—参考”顺序。与前两页的工作台侧栏不同，它使用顶部导航和独立阅读宽度，不把所有页面强制塞进同一种布局。

## 3. 可以直接体验的操作

### 01 / 综述矩阵

- 搜索标题、作者或关键词；按材料状态和方法筛选；按日期或标题排序。
- 每个长文本单元格独立展开和收起；表格内部横向、纵向滚动。窄屏不固定第一列，避免遮住剩余内容。
- “显示列”控制比较维度；“舒适 / 紧凑”切换表格密度。
- 勾选论文；全选仅作用于当前筛选结果。未全选时出现半选状态。已选择但暂时被筛选隐藏的论文仍计入选择总数。
- “导出所选”导出选中的本地示例；普通导出作用于当前筛选结果。支持 Markdown 与 CSV。
- 保存表单有空值校验；保存名称及论文集合到带 `pd-ui-demo-` 前缀的浏览器存储。再次打开同一存储环境时会尝试恢复。
- 移除需要确认，且只影响当前预览；“恢复样例”可还原本地表格。
- 论文标题打开阅读卡，支持本地批注、收藏、BibTeX 复制和下载。
- “总览 / 综述矩阵 / 深读 / 问题”均可切换；深读页明确显示没有接入真实记录，问题页中的追踪开关仅演示外观。
- “综述骨架”演示加载与预置结果，不调用模型、不生成真实综述、不伪造后台进度。

### 02 / 数据集地图

- 名称、缩写、所有方搜索；六个条件联合筛选；使用篇数或名称排序。
- 已选条件生成可移除标签；支持一键清除筛选。
- 默认显示 4 条，点击“加载更多”显示剩余节选，最多 8 条。
- 点击资源标题或“查看详情”打开登记卡，显示所有方、单位、地区、时间范围和获取方式。
- “按问题找数据”只按预设关键词匹配本地记录。界面明确说明没有执行原站语义检索，匹配结果不构成研究数据选择建议。
- 无结果状态说明“本地节选无匹配”，不会错误暗示原站没有相关数据。
- 保留“找不到？搜索全部数据集标签”入口，但本地搜索范围仍限定于这 8 条记录。

### 03 / 研究日报

- 目录定位到今日地图、必读、视野更新、拓展、参考；滚动时显示当前阅读区。
- 每篇论文的阅读提示可独立展开，不需要依赖鼠标悬停阅读长文本。
- 保存/取消保存为浏览器内演示收藏；不会修改原站论文库。
- BibTeX 可以复制或下载；书目字段不完整时不编造 DOI、卷期、页码。
- Markdown 导出包含本稿的 6 篇节选，并附来源与演示说明。
- “导出 PDF”调用浏览器打印，用户可选择“另存为 PDF”；没有内置 PDF 生成服务。
- 订阅与更换方向会说明本地范围，并提供原站入口；不会收集邮箱、创建订阅或伪造其他方向的日报。

## 4. 组件覆盖

三页共用同一套样式和状态规则，覆盖上一份方案的十二类组件家族。覆盖某一“家族”不等于实现该家族下的每一个业务功能。

| 组件家族 | 矩阵 | 数据地图 | 日报 | 说明 |
|---|---|---|---|---|
| A01 框架与导航 | 侧栏、页签 | 侧栏、页面入口 | 顶栏、阅读目录 | 相同视觉规则，不强制相同布局 |
| A02 文字与图标 | 标题、元信息 | 标题、图标、登记字段 | 长文、段落、来源 | 无外部字体依赖；品牌仅使用文字 |
| A03 按钮与链接 | 完整主次、危险、禁用 | 搜索、详情、清除 | 导出、保存、原文 | 同一按钮基样式与变体 |
| A04 输入与表单 | 搜索、命名、批注 | 研究问题、名称、标签搜索 | 评审工具 | 字段标签、说明、空值错误 |
| A05 选择与范围 | 下拉、全选、半选、开关 | 多条件下拉 | 评审工具 | 数值滑杆与单选仅放在独立评审工具中 |
| A06 标签与元信息 | 材料范围、计数 | 数据类型、获取方式、数量 | 日期、材料范围、来源 | 不把摘要级当成错误，不把使用频次当成推荐度 |
| A07 卡片与信息面板 | 总览、问题、阅读卡 | 数据集卡、登记详情 | 摘要、阅读卡、参考 | 内容骨架复用，业务字段分开 |
| A08 表格与矩阵 | 主要示例 | 不强行添加 | 不强行添加 | 宽表、排序、选择与列显隐集中在矩阵 |
| A09 浮层与菜单 | 菜单、弹窗、抽屉、确认 | 详情抽屉、评审工具 | 引用、订阅说明、评审工具 | 原型中的详情抽屉不代表原站已经采用抽屉 |
| A10 状态与反馈 | 真实本地操作反馈、模拟生成 | 无结果、加载更多 | 收藏、复制、导出 | 全页加载、空白、错误、未登录通过评审工具查看 |
| A11 滚动与展开 | 宽表、单元格、流程折叠 | 筛选展开、口径说明 | 阅读展开、目录定位 | 保留浏览器原生滚动，不劫持滚轮 |
| A12 代码与媒体内容 | BibTeX、骨架文本 | 不强行添加 | BibTeX | 以代码内容为代表；不为凑齐组件新增图表/网络图/图片查看器 |

未默认新增：业务中的数值筛选滑杆、日期查询、API Key 管理、密码表单、面板拖动分隔线、图表引擎、引用网络、拖拽排序等。

## 5. 独立的“评审工具”

点击右上角调整图标，可体验：

- 正常、加载、空内容、错误、未登录五种展示状态。
- 14–18px 正文字号滑杆及同步数字输入，作为数值控件示例。
- 舒适 / 紧凑密度；组件边界标记；减少动效。
- 主按钮、次按钮、禁用按钮、加载按钮的同族外观。

这些设置只用于评审原型，不表示要向原站新增同样的设置面板。它们也不改变真实权限或任务状态。

采集与整理日期：2026-11-02。网页会更新，快照不是实时数据。

日报沿用当时可读的 **2026-11-01** 宏观方向示例书目，原站完整报告为 13 篇，本稿节选 6 篇。其中必读 3 篇、视野更新 2 篇、拓展 1 篇；界面计数只对应本稿节选。

数据地图采用 8 条原站公开登记记录中的主要字段，包括 PISA、HRS、WDI、ESS、CHARLS、PSID、CFPS、Compustat。所有方名称个别采用缩写，分类筛选为本地演示分组；正式接入应使用原站字段和值。记录的获取方式不是本原型对许可、开放资格或最新政策的独立确认。

当前连接无法读取用户浏览器的登录态，因此**没有声称检查了真实登录后的综述矩阵、深读或账户数据**。矩阵是根据公开工作台职责、前一份组件方案和公开书目重建的展示，不是原 DOM 的逐像素复刻。论文阅读提示是人工编写的演示内容，不是论文全文结论或正式抽取结果。

原型保留产品文字品牌，没有绘制一个新 Logo。强调色为演示选值，并非从原站截图采样。没有用推测的“原版截图”制造前后对比。

## 7. 接入边界：哪些只涉及样式，哪些需要前端代码

| 类型 | 可供开发者采用的内容 | 需要注意 |
|---|---|---|
| S：统一外观 | 字号、字重、间距、边框、圆角、按钮变体、卡片、标签、已有状态的视觉 | 对应现有 DOM 和组件，不要求更换框架 |
| U：局部交互 | 单元格折叠、列显隐、详情抽屉、菜单、弹窗、键盘操作等 | 需要少量 HTML/JS 或现有组件参数；原站已支持的继续复用，未支持的单独确认 |
| 本地演示逻辑 | 静态记录筛选、预置骨架、演示收藏、导出样例、评审工具 | 不能直接当作生产实现；须替换为真实接口/事件和原有权限判断 |

每份 HTML 的主要结构：

```text
#pd-ui                      独立样式作用域
├── .app                    宿主布局（工作台 / 日报两种变体）
├── .topbar                 标题与预览导航
├── main                    原页面对应内容
├── dialog                  弹窗、详情抽屉、评审工具
└── 内嵌 script             演示数据与本地交互
```

CSS 主要受 `#pd-ui` 约束。`html`/`body` 的宿主重置、打印规则和独立演示导航是为单独打开 HTML 准备的，**不可连同整份样式直接覆盖原网站**。正式接入需要开发者核对原根节点、层叠、滚动容器、路由、数据字段和事件绑定。

三个 HTML 的共用 CSS/JS 内容一致，便于后续抽取，而不是三套互不兼容的设计。此阶段优先提供独立可运行文件；在视觉确认后再拆分生产组件。

没有后端连接、网络请求、真实密钥、支付流程、鉴权逻辑或埋点。代码中的外部 URL 只用于用户主动打开来源。浏览器可能发出自身的导航/安全检查请求，本稿不实现这些行为。

## 8. 测试说明

已在 Chromium 中渲染并执行本地交互检查：宽表筛选、半选、展开、列显隐、排序、表单校验、移除还原、键盘页签、抽屉、复制、CSV/Markdown/BibTeX 下载、状态预览、字号滑杆、数据集联合筛选、日报收藏、订阅说明等。

桌面和窄屏已检查整页横向溢出、抽屉宽度和移动导航。系统测试环境限制了文件/本机 URL 导航，因此测试采用浏览器直接装载 HTML 内容；不声称已在用户的 Safari 或手机真机测试。

存储不可用时的明确提示与临时状态已验证；持久存储是否可用仍取决于用户浏览器及其文件来源策略。打印按钮已验证会调用打印流程，但 PDF 的最终分页由浏览器设置决定。

**这三份是静态重设计评审原型，不是已经接入原网站的生产页面。**
