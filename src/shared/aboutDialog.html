原型与接入说明

共享 CSS / JS · 可离线预览 · 开发素材已分离

这些页面是全站静态准接入稿，不会登录、抓取账户数据、执行在线订阅或调用 AI。

来源与数据边界

页面名称、主要业务分区与公开书目参考 PaperDaily 公开页面。登录后的矩阵、深读与账户状态未能直接读取，已使用明确标注的本地演示内容。

哪些按钮真的可以操作？

本地筛选、展开、列显隐、选择、复制、下载和演示收藏可以操作。保存只写入带 pd-ui-demo 前缀的浏览器演示记录，失败时会明确提示。

哪些只是 UI 演示？

综述生成展示预置内容，不调用模型；错误、未登录和加载状态是手动切换。原站入口会在新标签页打开，线上服务仍由 PaperDaily 管理。

视觉边界

沿用 PaperDaily 文字品牌，没有重绘 Logo。绿色强调色为本稿演示选值，不声称是原站采样色。样式可独立抽取，但正式接入仍需匹配现有 DOM 和状态逻辑。
