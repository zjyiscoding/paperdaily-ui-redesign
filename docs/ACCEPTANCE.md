# 原项目接入验收清单

## 设计基线

- [ ] 原稿已确认的颜色、字号、按钮状态、密度没有另行重设计。
- [ ] 共享 CSS 只加载一次，根 `#pd-ui` 唯一，浮层在正确作用域。
- [ ] 原路由、页面顺序、功能入口、文案语义保留；本地预览文件不当作线上路由规范。
- [ ] 现有图表引擎、文档查看器、图标源可继续使用，不为换肤增加库依赖。

## 业务绑定

- [ ] 不加载 demo/、preview-host.css、评审工具或切页器。
- [ ] 替换所有模拟记录和未知字段；空值与0分开处理。
- [ ] 动作只触发一次；已有框架事件与可选 controller 不重复绑定。
- [ ] 保存/导出/生成/删除依真实返回判断，不用固定计时器假装完成。
- [ ] API参数、鉴权、计费、分页、排序、任务取消和CSRF沿用原有方案。
- [ ] 用户资料、密码、真实Key不进入本地演示存储或日志。
- [ ] 业务组件卸载时清理事件/请求；失败不清空用户未保存输入。

## 全状态回归

- [ ] 正常、加载、空数据、筛选无结果、网络错误、未登录、无权限分别展示。
- [ ] 摘要级/全文级、核验状态、公开/私有不混为同一字段。
- [ ] 所有按钮有hover/focus/disabled/loading适用状态。
- [ ] 全选范围明确；半选、筛选后隐藏选择、批量删除/导出范围已核对。
- [ ] 表格/代码仅内部横向滚动；展开后可读完整文字。
- [ ] 弹窗键盘焦点、Escape和关闭回到原触发器；危险操作确认规则正确。
- [ ] 真实数据量、超长中文/英文、缺字段、错字段与非法输入不破坏布局。
- [ ] Safari、Firefox、Chromium和目标移动设备按项目支持范围实测。
- [ ] 旧界面/feature flag可以回退；此次UI不需要改写数据库数据。

这是交付后的原项目清单，未勾选项不能当作已完成生产验证。独立原型已执行项目见 QA_REPORT.md。
