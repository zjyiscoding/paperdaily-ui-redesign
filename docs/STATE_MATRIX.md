# 状态与交互验收矩阵

| 状态 | 页面/组件表现 | 真实接入数据来源 |
|---|---|---|
| 正常 | 正文、列表、表格、卡片 | 原业务数据与字段 |
| 首次加载 | 骨架或明确加载提示 | 原请求 loading，不按时间造进度 |
| 无内容 | 对象尚未创建的反馈 | 原服务确认的空集合 |
| 筛选无结果 | 当前条件无匹配，可清除筛选 | 原筛选范围与分页口径 |
| 未登录 | 登录入口与原因 | 原会话状态 |
| 无权限 | 清楚说明无访问权限 | 原服务鉴权，不与未登录混用 |
| 网络/业务失败 | 可持续读取的错误说明，按原能力重试 | 原错误类型与可恢复操作 |
| 材料不足 | 摘要/全文缺失标签与限制 | 原材料范围字段 |
| 待核验 | 保留核验状态 | 不用材料标签代替质量判断 |
| 部分选中 | 复选框 indeterminate；说明选择范围 | 宿主的选中集合 |
| 提交中 | 同一按钮宽度、spinner、禁用重复提交 | 实际 Promise/任务状态 |
| 危险确认 | 对象、后果、取消与确认 | 原权限、可逆性与确认流程 |
| 表单错误 | 字段附近提示，焦点可定位 | 原校验规则 |
| 成功反馈 | 文案与实际结果一致 | 真实服务确认 |
| 紧凑/舒适 | 相同组件不同密度 | 原产品是否提供此偏好决定是否暴露设置 |
| 宽窄屏 | 大字号不无限缩小，宽表内部滚动 | 内容空间/现有布局 |

每页评审工具可切换5种全页状态、14–18px字号、密度与组件边界。它只模拟展示，不变更服务状态。默认外观保持获确认原型。

组件页补充纯图标、危险、禁用、加载按钮；单选/多选/半选；开关；日期与范围；单/双滑杆；Tooltip；弹窗/抽屉；原生折叠；拖动分隔线与键盘替代；代码/图片/图表。没有在原业务页面硬塞这些控件。

正式接入需要补测的组合：同一请求失败后重试、并发保存、权限变化、登录过期、真实长文本、多语言、非空过期缓存、真实行数与分页、原查看器/图表交互。静态样例无法替代这些端到端状态。
